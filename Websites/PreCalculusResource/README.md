# Polynomial Long Division Lesson

An interactive resource website for learning polynomial long division via notes and questions.

# Motive

This project was created for a Pre-Calculus project. We were tasked with creating a resource which would teach a beginner a topic in Pre-Calculus of choice. This project could take the form of anything, from a video, a worksheet, and in my case a website.

# Features

* Math equation rendering using [MathJax](https://www.mathjax.org/).
* Tooltip definitions for keywords and concepts.
* Quiz with three questions.
* Handful of animations for aesthetics, including a cool background animation.
