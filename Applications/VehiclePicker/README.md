# Vehicle Picker

An app that recommends transport vehicles based on trip distance.

# Motive

This project was my submission for the AP Computer Science Create Performance Task and met all its requirements. It's also the main showcase of Compose Library, both built during my Senior year of high school.

# Features

* Uses my custom ui library; [Compose Library](https://github.com/The-Nice-One/PlaygroundProjects/tree/main/Libraries/ComposeLibrary)
* Animations for user feedback; hover and click.
* Interactive themed elements; buttons and dropdowns.
